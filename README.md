# Land-suitability-project

Description: This project aims to build a land suitability analysis (LSA) tool that allows users to independently weigh planning criteria.

Research Questions:

    How can combining environmental, infrastructure, and economic data influence the identification of development potential? 
    Does allowing users to assign weights to planning criteria improve the site planning process?  
    How does comparing minimum facility size and contiguous developable area in the LSA change site selection?

File Organization: The main folders include: clean_data, figures, raw_data, scripts, and archive


Requirements: This project requires R and data from NYC Open Data. 
    Primary Land Use Tax Lot Output - Map (MapPLUTO)
